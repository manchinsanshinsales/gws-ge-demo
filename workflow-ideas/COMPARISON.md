## ⚠️ リスク・注意点

### アイディア1: メールルーティング

**リスク:**
- [ ] 誤分類による対応漏れ (信頼度 < 80% の場合)
- [ ] Gemini API 利用料の急増（大量メール時）
- [ ] ラベル体系の複雑化

**対策:**
- 信頼度しきい値を設定 (デフォルト 85%)
- エラー監視ダッシュボード
- 月1回ルール見直し

---

### アイディア2: ミーティング準備自動化

**リスク:**
- [ ] プライベート情報の漏洩（テンプレート共有時）
- [ ] API レート制限（多数のイベント参照時）
- [ ] 資料検索の不正確性

**対策:**
- テンプレートの権限制限
- バッチ処理でリクエスト削減
- キーワード手動指定機能

---

### アイディア3: 経費報告書自動生成

**リスク:** ⚠️ **最も高い**
- [ ] OCR 誤認識による金額エラー
- [ ] 領収書紛失リスク（Drive 削除時）
- [ ] 規制対応（税務調査時）
- [ ] 個人情報（クレジットカード番号）露出

**対策:**
- [ ] 確信度 < 90% は手動確認フロー
- [ ] Drive バックアップ + バージョン管理
- [ ] 監査ログ記録 (who/when/what)
- [ ] PII マスキング + 暗号化
- [ ] コンプライアンスチェック
