# インテリジェント メールルーティング

## 📌 概要

受信メールの内容を自動分析し、適切なチームメンバーに自動割り当てするワークフロー。Gemini の自然言語処理で「重要度」「カテゴリ」「優先度」を判定し、ルールに基づいて自動振り分けします。

```
受信メール
    ↓ [Apps Script トリガー]
[Gemini で内容分析]
    ├─ 重要度判定 (高/中/低)
    ├─ カテゴリ分類 (営業/サポート/IT等)
    └─ 優先度判定 (今日/今週/今月)
    ↓
[Google Sheets でルール適用]
    ├─ 担当者割り当て
    ├─ ラベル付与
    └─ フォルダ移動
    ↓
[割り当てられたメンバーに通知]（Chat or Email）
```

| カテゴリ | 重要度 | 割り当て先 | ラベル | 対応時間 |
|---------|-------|---------|--------|----------|
|営業 | 高 | sales-team@company.com | 🔴High | 1h |
| サポート | 中 | support-team@company.com | 🟡Medium | 4h |

## 🚀 実装ステップ

### **ステップ1: Google Sheets ドキュメント作成**（15分）
1. [Google Sheets](https://sheets.google.com) 開く
2. 新しいスプレッドシート作成 → "メールルーティング ルール定義"
3. 上記のテーブル構成を作成
4. スプレッドシート ID をコピー → 保管

### **ステップ2: Apps Script プロジェクト作成**（20分）
1. Google Apps Script 開く → 新しいプロジェクト作成
2. `main.gs`, `gemini-helper.gs`, `sheets-helper.gs` を作成
3. 下記の「サンプルコード」セクションからコードをコピペ
4. API & スコープの有効化

### **ステップ3: Gemini API 統合**（10分）
1. [Google Cloud Console](https://console.cloud.google.com)
2. Generative Language API 有効化
3. API キーを作成
4. `CONFIG.GEMINI_API_KEY` に設定

### **ステップ4: Gmail トリガー設定**（5分）
```javascript
// Apps Script 側で以下を実行
function setupTrigger() {
  // 新規メール受信時にトリガー設定
  ScriptApp.newTrigger("onNewMail")
    .forSpreadsheet(SpreadsheetApp.openById(CONFIG.SPREADSHEET_ID))
    .onEdit()
    .create();
}
```

### **ステップ5: テスト & 検証**（30分）
1. テストメール送信
2. ログを確認（Sheets）
3. ルールが正しく適用されるか確認
4. 本番化前に2-3日間テスト運用

## ⚠️ 注意点とベストプラクティス

### セキュリティ
- [ ] メール内容を外部サービスに送信しない（オンデバイス処理推奨）
- [ ] Gemini API キーを Apps Script スクリプト設定で管理
- [ ] ログシートに機密情報を含めない

### パフォーマンス
- [ ] Gemini 呼び出しはバッチ処理で効率化
- [ ] 1時間に最大120リクエスト制限に注意
- [ ] キャッシング層を検討（同じパターンは再利用）

### 運用
- [ ] 週1回、ルール定義の見直し
- [ ] 月1回、誤分類レポートを確認
